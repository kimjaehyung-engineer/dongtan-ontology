# 동탄트램 지반 엔지니어링 RAG MVP (DONGTAN_TRAM_GEO_RAG_MVP)

본 저장소는 동탄트램(동탄도시철도) 프로젝트의 지반조사, 설계보고서, 시험성적서, 설계변경 및 각종 기준 문서를 **설계 단계별(기본계획 → 기술제안 → 실시설계)**로 정밀 분류하고, 검증 가능한 지반 엔지니어링 RAG(검색 증강 생성) 서비스를 구축하기 위한 표준 작업 공간입니다.

---

## 📂 프로젝트 디렉토리 트리 구조 (테스트 린 RAG 버전)

```text
DONGTAN_TRAM_GEO_RAG_MVP/
│
├─ 00_INBOX/                                   # 신규 입고 문서 및 임시 대기소
│
├─ 01_SOURCE_DOCUMENTS/                        # 핵심 지반 기술도서 (테스트 정예화)
│   ├─ 01_기본계획/
│   │   ├─ 01_지반조사/                        # 입찰안내서 지반조건, 시추주상도 종합본(1, 2공구, 차량기지)
│   │   └─ 02_지반설계/                        # 제4편 토질 및 기초 보고서(본문, 부속)
│   │
│   └─ 02_기술제안/
│       ├─ 01_지반조사/                        # 제안 시추주상도, 유향유속/물리탐사/검층 종합보고서
│       └─ 02_지반설계/                        # 기술제안 지반설계보고서, 가시설 검토서, 지반정수 총괄표

├─ 02_COMMON_REFERENCE/                        # 공통 표준 기준 및 기술 참고자료
│
├─ 03_AI_PROCESSED/                            # AI 문서 파싱 및 전처리 데이터
│   ├─ 01_MARKDOWN/                           # 정제된 텍스트 본문 (장/절/항 계층 보존)
│   ├─ 02_JSON/                               # 구조화된 본문/문단 데이터
│   ├─ 03_TABLES/                             # 추출된 지반정수/시험 수치 표 (CSV, Markdown)
│   ├─ 04_IMAGES/                             # 도면, 주상도 그래픽, 시험 차트
│   ├─ 05_CHUNKS/                             # 임베딩용 도메인 단위 청크
│   └─ 06_FAILED/                             # 파싱 오류 문서
│
├─ 04_METADATA/                                # 정밀 메타데이터 마스터 대장 및 스키마
├─ 05_RAG_INDEX/                               # Dense 벡터 인덱스 및 Sparse(BM25) 색인
├─ 06_VALIDATION/                              # RAG 성능 벤치마크 및 신뢰성 검증
├─ 07_APP/                                     # RAG 애플리케이션
├─ 08_LOGS/                                    # 파이프라인 및 서비스 운영 로그
└─ 90_ARCHIVE/                                 # 구버전 원시자료 전체 백업 (20260915_원시자료_전체백업)
```

## 🚀 파이프라인 워크플로우

1. **인입 및 분류**: `00_INBOX`로 들어온 문서는 확인 후 설계 단계(`기본계획` / `기술제안` / `실시설계`) 및 공종 폴더(`01_SOURCE_DOCUMENTS`)로 분류 배치합니다.
2. **메타데이터 등록**: 문서는 즉시 `04_METADATA/`의 엑셀 대장(`metadata_master.xlsx`, `borehole_register.xlsx` 등)에 STA. 측점, 지층, 날짜 등의 고유 속성과 함께 등록됩니다.
3. **AI 전처리**: OCR 및 전처리 파서가 텍스트, 표, 이미지를 분리 추출하여 `03_AI_PROCESSED`에 저장합니다.
4. **인덱싱 & 검색**: 지반정수, 시추주상도, 보고서 본문을 각각 최적화된 청킹 및 메타데이터 필터와 함께 `05_RAG_INDEX`에 색인합니다.
5. **검증**: `06_VALIDATION`의 Ground Truth 질의응답을 통해 답변의 정확도와 출처 인용 일치율을 지속적으로 검증합니다.
