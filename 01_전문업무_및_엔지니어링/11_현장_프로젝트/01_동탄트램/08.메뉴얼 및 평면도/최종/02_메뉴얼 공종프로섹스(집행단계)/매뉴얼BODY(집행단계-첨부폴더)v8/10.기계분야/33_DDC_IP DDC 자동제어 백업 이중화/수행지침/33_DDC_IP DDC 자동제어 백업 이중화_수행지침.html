원격 관제 DDC 패널, BACnet 표준 통신, 메인/백업 중앙 감시 서버 무중단 절환 체계

🔍 도식을 클릭하면 고해상도 대형 팝업으로 확대됩니다.
2. 단계별 마스터 수행 절차 (Step-by-Step)
STEP 1 STEP 1: 자동제어 I/O 포인트 일람표 및 통신 선로 설계 대조
수천 개 감시/제어 포인트 1:1 매핑
  • 정거장 31개소 및 차량기지 공조/위생/소방 감시 제어 포인트(DI, DO, AI, AO) 총괄 취합
  • 광케이블(Optical Fiber) 이중 링(Ring) 통신망 토폴로지 및 IP 주소 할당표 확정
  • DDC 캐비닛 내부 전원(AC 220V ⟶ DC 24V SMPS) 및 노이즈 차폐 접지(≤ 10Ω) 계획
STEP 2 STEP 2: 기계실 IP DDC 패널 가설 및 필드 센서/밸브 배선
온습도센서, 차압스위치, 비례제어밸브 결선
  • 기계실 벽면에 IP DDC 제어반 안착 및 차폐 실드 케이블(CVVSB) 포설
  • 덕트 온·습도 센서, 필터 차압 스위치(DPS), 2방/3방 비례 제어 밸브 모터 액추에이터 결선
  • 소화펌프 기동 상태, 저수조 수위 레벨계 신호선 DDC 입력 단자 1:1 결선
STEP 3 STEP 3: 중앙관제 그래픽 UI 구축 및 백업 서버 이중화 구성
실시간 SCADA 화면 및 DB 미러링
  • 정거장별 3D 입체 계통도, 공조기 운전 상태, 경보 팝업 그래픽 화면 설계
  • 중앙 방재실 Main 서버와 Backup 서버 간 기가비트 이중화 하트비트(Heartbeat) 라인 구성
  • 메인 서버 전원 강제 차단 모의 시험 시 백업 서버가 1초 이내 제어권을 인수하는 무중단 검증
STEP 4 STEP 4: Point-to-Point 전수 시험 및 원격 제어 시운전
현장 기기 ↔ 중앙 화면 1:1 연동 검측
  • 엔지니어 2인 1조로 현장 밸브 강제 구동 시 중앙 모니터 개도율(0~100%) 일치 확인
  • 저수조 수위 센서 단선 시 즉시 경보음 발생 및 경보 이력 데이터베이스 자동 저장 확인
  • 감리원 입회 하에 자동제어 종합 시운전 완료 보고서 승인 날인
3. 핵심 엔지니어링 용어 해설
• DDC (Direct Digital Control): 현장 기계실에서 마이크로컴퓨터가 센서 값을 직접 읽어 밸브와 모터를 정밀하게 자동 제어하는 분산 제어기
• BACnet (Building Automation and Control networks): 건물 자동제어 분야에서 제조사가 다른 기기들끼리 서로 대화할 수 있도록 만든 국제 표준 통신 규격
• Active-Standby 이중화: 평상시에는 메인 컴퓨터가 일하고, 고장 나는 순간 대기 중이던 백업 컴퓨터가 즉시 이어받아 멈추지 않는 시스템
